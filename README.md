# Norte Jato
MVP em React, TypeScript, Tailwind CSS e Vite.

Execute `npm install` e `npm run dev`. Para produção: `npm run build`. Os arquivos finais ficam em `dist/`.

Links de WhatsApp, Instagram e FilaClick estão no início de `src/App.tsx`. O agendamento abre o serviço externo; o site não confirma reservas.

Fotos ilustrativas do Unsplash e fontes do Google Fonts dependem desses serviços. Substitua as fotos por imagens autorizadas do negócio antes da versão comercial final. Dados de contato e horários seguem o briefing e devem ser confirmados com a empresa.

Enviar ao GitHub publica o código; hospedar o site exige publicar a pasta dist em um serviço de hospedagem.
